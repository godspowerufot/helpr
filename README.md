# MSF Next.js Scaffold

This project is generated by `@msflib/react-template` and starts with a standard folder architecture for new frontend apps.

## Default Stack

- Next.js (App Router)
- Tailwind CSS
- Material UI
- TanStack Query
- `@msflib/react-components`

## Optional During Scaffold

- Multi-tenancy setup (`@msflib/core`, `@msflib/react-shared`)
- Extra `@msflib/*` modules from the prompt

## Root Architecture

```text
app/
components/
styles/
data/
columns/
assets/
constant/
context/
api/
types/
utils/
theme/
hooks/
dynamics/
```

## App Route Groups

```text
app/
  (public)/
    components/
    data/
    layout.tsx
    page.tsx
  (auth)/
    layout.tsx
    components/
    data/
    login/
      components/
      data/
      page.tsx
    register/
      components/
      data/
      page.tsx
  (protected)/
    components/
    data/
    layout.tsx
    admin/
      page.tsx
      lesson/            # reference feature: list, manage (?id=), view (?id=)
```

## Config + Environment

- `application.config.ts` stores MSF app settings including tenancy scope.
- `.env.example` contains baseline environment variables for local development.
- `.env.local` is generated by the scaffold command.

All conventions (structure, naming, routing, theming, msflib usage) are in [`docs/IMPLEMENTATION_GUIDE.md`](docs/IMPLEMENTATION_GUIDE.md). AI agents load it through `AGENTS.md` / `CLAUDE.md`.
